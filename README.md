# Personal Expense & Budget Tracker

Day 1 of 4 - in progress

A simple command-line application to track personal expenses and manage daily spending.

## Day 1 Features
- Add an expense with validation (amount, category, description, date)
- View all recorded expenses in a formatted table
- Persistent storage using a CSV file (`expenses.csv`)
- Simple menu-driven CLI interface
- Safe error handling for user inputs and file operations

## How to Run
Ensure you have Python installed, then run:

```bash
python expense_tracker.py
```
